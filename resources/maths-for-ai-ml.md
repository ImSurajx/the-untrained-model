## 1. algebra + precalculus

| topic | sub-topic | priority |
|---|---|---|
| functions | domain/range, graphs, transformations | must-do |
| quadratics & polynomials | - | medium |
| rational functions | inequalities, composition, inverses | medium |
| exponents & logarithms | - | must-do |
| sequences & series | summation notation | must-do |
| trigonometry | angles, unit circle, identities | skip |

## 4. linear algebra

| topic | sub-topic | priority |
|---|---|---|
| linear equations | elimination, inverses, lu decomposition | must-do |
| vector spaces | column/null space, basis, dimension | must-do |
| matrix spaces | rank, graphs/networks | useful |
| orthogonality | projections, least squares | must-do |
| determinants | cofactors, cramer's rule | useful |
| eigenvalues & eigenvectors | diagonalization | must-do |
| symmetric matrices | positive definiteness | must-do |
| svd | singular value decomposition | must-do |
| linear transformations | change of basis | must-do |
| other | diff. equations, markov, fourier, pseudoinverses | skip |

## 5. probability & statistics

| topic | sub-topic | priority |
|---|---|---|
| probability basics | counting, conditional probability, bayes | must-do (sequential) |
| random variables | expectation, distributions (poisson, uniform, normal) | must-do (sequential) |
| exponential distribution | moment generating functions | must-do |
| joint distributions | covariance, correlation, transformations | must-do |
| multinomial, cauchy | - | skip |
| beta, gamma distributions | - | skip |
| order statistics | conditional expectation, inequalities | useful |
| large-sample theory | law of large numbers, central limit theorem | must-do |
| other distributions | chi-square, student-t, multivariate normal | useful |
| markov chains | - | skip |

## revision system (applies to every subject above)

| tool | purpose |
|---|---|
| [anki](https://apps.ankiweb.net) | spaced repetition flashcards |
| [notebooklm](https://notebooklm.google.com) | targeted gap-filling, study guides, flashcards |
| feynman technique | explain from memory, no notes |
| weekly cold-review | solve an old problem with no rewatching |
| confusion log | one line per confusion point, review every 2 weeks |
